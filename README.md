# leetcode-archive

**221 problems** solved in Python between **May 2023 and September 2024**, kept as a record
rather than a showcase. Each directory holds the solution and LeetCode's own problem statement.

This is the archive of my first sustained practice run. Current practice lives in a separate
workflow where an Obsidian note is the source of truth and solutions are reconciled into Git
with spaced-repetition review — see [pbairoliya.github.io](https://pbairoliya.github.io).

## Layout

```
<number>-<problem-slug>/
  <number>. <Problem Name>.python   # the solution
  README.md                         # the problem statement
```

The numeric prefix is LeetCode's problem ID, so `146-lru-cache/` is problem 146.

## What's in here

Heavier on the patterns that actually repeat in interviews: two pointers, sliding window,
monotonic stack, BFS/DFS on trees and grids, heaps, and dynamic programming. A few design
problems too — LRU cache, min stack, underground system, browser history — which are the ones
worth reading if you only read a handful.

## Honest notes

- Solutions are as I first wrote them. Some are not optimal, and none were cleaned up afterward.
- Commit dates reflect when each was solved; the repository was moved between my accounts in
  2026, so the repo is newer than the work.
